# BCIF FORMATTING FIX — Larger Text, Defined Lines, Bigger Checkboxes

## Problem
The current BCIF output (generated by `build_v4_template.py` / `bcifRenderer.js`) uses 
Arial Narrow at 7pt for checkbox items and 8pt for headers. At 100% zoom this is barely 
readable. Borders are faint (#999 at 0.5pt). Checkboxes (☑/☐) are tiny. The form looks 
washed out and unprofessional.

## Reference File
See `bcif-fill-test/output/BCIF_123865.docx` for the current (bad) formatting.

## Required Changes

Find the code that generates the BCIF document (likely in `build_v4_template.py` and/or 
`bcifRenderer.js`) and update ALL of the following:

### Font Sizes — INCREASE EVERYTHING

| Element | Current | New |
|---------|---------|-----|
| Section headers ("BASE CLAIM INFORMATION FORM", "OPTIONS / EQUIPMENT", etc.) | Arial Narrow 11pt bold | **Arial 14pt bold** |
| Table category headers ("Power / Convenience", "Safety", "Seats", etc.) | Arial Narrow 8pt bold | **Arial 10pt bold** |
| Checkbox labels ("Power Steering", "Air Conditioning", etc.) | Arial Narrow 7pt | **Arial 9pt** |
| Checkbox symbols (☑ and ☐) | Same size as label (7pt) | **12pt** — make them visually prominent |
| Key-value labels ("Year:", "Make:", "VIN:") | Arial Narrow 8pt bold | **Arial 9pt bold** |
| Key-value data ("2022", "HONDA", etc.) | Arial Narrow 8pt | **Arial 9pt** |
| Condition table text | Arial Narrow 7-8pt | **Arial 9pt** |
| Condition table headers ("Condition", "0 Poor", etc.) | Arial Narrow 8pt | **Arial 9pt bold** |

### CRITICAL: Checkbox Character Sizing

The checkbox character (☑ or ☐) should be a SEPARATE TextRun from the label text, 
so it can be sized independently:

```javascript
// WRONG — same size for checkbox and label
new TextRun({ text: "☑ Power Steering", font: "Arial", size: 18 })

// RIGHT — checkbox larger than label
new Paragraph({ children: [
    new TextRun({ text: "☑ ", font: "Arial", size: 24 }),      // 12pt checkbox
    new TextRun({ text: "Power Steering", font: "Arial", size: 18 }) // 9pt label
]})
```

This makes the checkbox visually prominent while keeping labels readable.

### Borders — MAKE THEM DEFINED

| Element | Current | New |
|---------|---------|-----|
| All table borders | size: 4 (0.5pt), color: #999999 | **size: 8 (1pt), color: #555555** |
| Section header underlines | Same faint borders | **size: 12 (1.5pt), color: #333333** |

In docx-js border size units: size=8 means 1pt, size=12 means 1.5pt.

### Cell Padding — ADD BREATHING ROOM

Currently there are NO cell margins. Add to ALL table cells:

```javascript
margins: { top: 60, bottom: 60, left: 100, right: 100 }  // DXA units
```

For checkbox option cells specifically:
```javascript
margins: { top: 40, bottom: 40, left: 80, right: 80 }
```

### Row Heights — SET MINIMUMS

Add explicit minimum row heights so rows aren't cramped:

| Table Type | Min Row Height |
|------------|---------------|
| Key-value rows (claim info, vehicle info) | **320 DXA** |
| Checkbox option rows | **300 DXA** |
| Condition rating rows | **340 DXA** |
| Category header rows | **360 DXA** |

### Section Header Styling

The section headers ("BASE CLAIM INFORMATION FORM", "OPTIONS / EQUIPMENT", etc.) 
should be more visually distinct:

```javascript
// Current: plain bold text
// New: Navy background bar (same style as claim summary)
new Table({
    width: { size: FULL, type: WidthType.DXA },
    columnWidths: [FULL],
    rows: [new TableRow({ children: [new TableCell({
        shading: { fill: "1B2A4A", type: ShadingType.CLEAR },
        borders: noBorders,
        margins: { top: 80, bottom: 80, left: 160, right: 160 },
        children: [new Paragraph({ children: [
            new TextRun({ text: "OPTIONS / EQUIPMENT", bold: true, 
                font: "Arial", size: 24, color: "FFFFFF" })  // 12pt white on navy
        ]})]
    })]})],
})
```

### Checkbox Grid Tables — WIDER CELLS

Current cell width is 2700 DXA (~1.875"). For a 4-column option grid on US Letter 
(9360 DXA content width), each cell should be **2340 DXA** with the table at full width:

```javascript
width: { size: 9360, type: WidthType.DXA },
columnWidths: [2340, 2340, 2340, 2340],
```

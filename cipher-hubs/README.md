# Cipher Hubs

A simple field hub locator built from the Focus fiber hub workbook.

## What it does

- Search by OLT, hub number, road, development, cabinet, or notes.
- Open an estimated hub location in Google Maps.
- Save your exact GPS position when standing at a cabinet.
- Mark favorites and recent hubs.
- Build a quick route pad with hubs and plain addresses.
- Works offline after first load for searching saved hub data.

## Field workflow

1. Search a hub like `SSDF 3`.
2. Tap **Navigate** to open Google Maps using the best spreadsheet description.
3. Once standing at the cabinet, tap **Save GPS**.
4. Next time, navigation uses the verified coordinates instead of the estimate.

Verified locations are stored locally in the browser on your phone.
